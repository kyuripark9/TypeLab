# TypeLab: LinkedIn post

What's in this folder:

- `TypeLab-LinkedIn-carousel.pdf`: 7 pages at 4:5. In LinkedIn, choose **Add a document** and upload it to make a swipeable carousel.
- `slides/TypeLab-01.png` to `TypeLab-07.png`: the same slides as 2160×2700 images (portfolio, Behance, Instagram).
- `source/`: what the slides are built from. Every letter on them is drawn by TypeLab's own engine. To change the wording, edit `build.mts`, then run it and `capture.mjs` (instructions at the top of each file).

## The post (English)

I couldn't find the font in my head. So I built a tool to make it.

This summer, as a junior graphic designer on Clayco's Branding Experience team, I was researching new letterforms for a project. Drawing each idea by hand took days. Downloading fonts to compare only showed me what already existed.

So in October, I gave myself one month to build the tool I wished I had.

Meet TypeLab 👉 typelab.ink

Move a slider and every letter redraws, live. Start from one of 22 original typefaces, then shape width, contrast, curves, corners and stroke ends, down to the form of a single "a". Add halftone, pixels or rough print edges. Fine-tune any letter point by point. Then export a real .otf family you can install and use anywhere.

I built it with Claude Code. The first version came fast. Making it reliable didn't: with near-endless combinations, letters could break in near-endless ways. So I had TypeLab test itself, 5,000 random setting mixes per round, until broken designs went from 149 to almost zero. Then I still checked every letter by eye.

My biggest takeaway: AI can turn a designer's idea into a real product, but design judgment is what makes it good.

It's free to try. What would you design with it? 👇

#TypeDesign #Typography #GraphicDesign #ProductDesign #AI #ClaudeCode

## 한국어 (참고용: 위 영어 글과 같은 내용)

머릿속에 있는 폰트를 찾을 수 없었어요. 그래서 그걸 만드는 툴을 직접 만들었습니다.

이번 여름, Clayco 브랜딩 익스피리언스 팀의 주니어 그래픽 디자이너로서 한 프로젝트를 위해 새로운 글자꼴을 리서치하고 있었어요. 아이디어 하나를 손으로 그리는 데 며칠이 걸렸고, 폰트를 내려받아 비교하면 이미 있는 것만 보였죠.

그래서 10월 한 달 동안, 제가 갖고 싶었던 바로 그 툴을 만들었습니다.

TypeLab을 소개합니다 👉 typelab.ink

슬라이더를 움직이면 모든 글자가 실시간으로 다시 그려져요. 22개의 오리지널 서체 중 하나에서 시작해 너비, 대비, 곡선, 모서리, 획 끝, 그리고 a 한 글자의 형태까지 다듬을 수 있어요. 하프톤, 픽셀, 거친 인쇄 질감 같은 효과도 더하고, 글자를 점 단위로 고친 뒤, 설치해서 어디서든 쓸 수 있는 .otf 폰트 패밀리로 내보낼 수 있어요.

개발은 Claude Code와 함께 했습니다. 첫 버전은 빨리 나왔지만, 안정적으로 만드는 건 달랐어요. 조합이 거의 무한하니 글자가 깨지는 방법도 거의 무한했거든요. 그래서 TypeLab이 스스로를 테스트하게 했어요. 라운드마다 5,000개의 무작위 설정 조합을 돌려, 깨진 디자인이 149개에서 거의 0개가 될 때까지요. 그리고 마지막엔 결국 제 눈으로 모든 글자를 직접 확인했습니다.

가장 크게 배운 점: AI는 디자이너의 아이디어를 실제 제품으로 만들어 주지만, 그걸 좋게 만드는 건 디자인 판단력이에요.

무료로 써볼 수 있어요. 여러분이라면 무엇을 디자인하실 건가요? 👇

## Posting tips

- **First lines:** only the first two or three lines show before "…see more", so the post opens on the same hook as slide 1.
- **The link:** LinkedIn tends to show posts with outside links to fewer people. If you like, take typelab.ink out of the body and post it as the first comment ("Try it here 👉 typelab.ink"). It's on the last slide either way.
- **Document title** (LinkedIn asks for one when you upload the PDF): `I built a font design tool in one month`
- **Reply to early comments** in the first hour; that is when LinkedIn decides how widely to show a post.
- **Your demo video** (`ad/Amibes-Display-demo.mp4`): one post can't hold both a document and a video, so share it a few days later as a follow-up ("Here's TypeLab in action, start to finish").
