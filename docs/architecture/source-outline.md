# Source Outline

A source program can enable Outline with `finish.outline: { rim: [0.006, 0.024], tolerance: 0.1 }`. Size interpolates the rim as a fraction of current cap height. Slice runs first. Outline preserves glyph advances and keeps the original editable Points separate from the finished ink. Old programs omit this policy and retain their existing output.

`shared/source/hollow.ts` flattens the complete render face with a cubic chord bound, normalizes its nonzero fill, and subtracts an inward offset. The result retains hairlines too narrow to hollow and does not consume existing counters. Work budgets, precision-collapse witnesses, and complete-edge clearance checks reject unsupported drawings with a typed `SourceEffectError`; they never substitute Solid output. The boundary certificate is one-sided, from the normalized face back to the original curves. It is not a universal two-sided topology proof.

Clipper2 is pinned to `clipper2-ts@2.0.1-18` under the Boost Software License. Its offset wrapper discards two internal union failures. The narrowly vendored emitted wrapper checks those results; its provenance records the exact upstream version and hash. `tools/masters/check-hollow-kernel.mjs` verifies this mechanical diff. Legacy boolean operations are unchanged.

OTF export uses `server/cff-precision.ts` for source Outline. It replaces the generated CFF1 paths with Type2 16.16 coordinates and retains the font's 1000 UPM, metrics, naming, licensing, and advances. Each absolute coordinate rounds once, with at most `1/131072` unit error per axis. Dense paths use bounded global subroutines so no CharString exceeds the format's 65,535-byte limit. The writer validates its template layout and recalculates table checksums. Other finishes retain the existing exporter. The encoding follows [Adobe Type2 specification 5177](https://adobe-type-tools.github.io/font-tech-notes/pdfs/5177.Type2.pdf), sections 3.2 and 4.7 and Appendix B.

Before integration, the neutral all-style geometry pass covered 8,382 cases (22 styles × 127 glyphs × three rims), with no rejected cases; its median was 5.6 ms and p95 20.2 ms. Eighteen focused geometry tests passed before the user deferred further testing. The known Serenade export reproduction now preserves H/g/j/& components and counters after actual serialization and reopening, with maximum coordinate error 0.000007627 units. FontTools independently reopened that artifact and verified its checksum and subroutine limits. These are bounded checks, not a completed all-control or visual interaction review. Full review and integration suites remain deferred.
